# VideoFX 96625 Filter — بوقاصد اليافعي

موقع ويب مستقل لعزل اللاعب بالذكاء الاصطناعي. لا يحتوي هذا المشروع على كود تطبيق Android؛ يرسل المقاطع القصيرة إلى خدمة Render للعزل والتركيب ثم يوفر الناتج للتنزيل.

## الوظائف

يقبل الموقع مقطعاً قصيراً، ويرسل الطلب إلى وضع `silhouette` في Render. نموذج AI يعزل اللاعب، يحوله إلى silhouette أسود، وينشئ خلفية ضبابية بيضاء/رمادية جديدة. يحافظ الناتج على أبعاد المصدر وFPS والاتجاه والصوت قدر الإمكان.

## تشغيل واجهة الموقع محلياً (اختياري)

يمكن تشغيل الواجهة من Termux، بينما تتم المعالجة عبر Render:

## التشغيل المحلي على Termux

ثبّت المتطلبات مرة واحدة لعرض الواجهة:



```bash
pkg update -y && pkg install python ffmpeg git -y
```

ثم شغّل الموقع والمعالجة معاً:

```bash
cd ~/videofx-style-web && bash run_termux.sh
```

ثم افتح `http://127.0.0.1:5000` في المتصفح. لا تغلق جلسة Termux أثناء المعالجة.

## حدود الخدمة

للحفاظ على استقرار الجوال، يُفضّل البدء بملفات أقل من 450MB. الحد الفعلي يتأثر بمدة الفيديو وذاكرة الجهاز ومساحة التخزين المتاحة.
