# VideoFX 96625 Filter — بوقاصد اليافعي

موقع ويب مستقل متخصص لتطبيق مظهر الفيديو المرجعي 96625 على أي فيديو. لا يحتوي هذا المشروع على كود تطبيق Android، ولا يعتمد على Render أو Expo؛ المعالجة تتم محلياً داخل Termux عبر FFmpeg.

## الوظائف

يقبل الموقع ملفات الفيديو ويطبق فلتر `Monochrome Noir 96625` داخل خادم Termux المحلي، ثم يعرض التقدم ويوفر تنزيل الناتج. يحافظ المسار على أبعاد المصدر واتجاهه وFPS والتوقيت، مع معالجة لونية ووضوح ونعومة خفيفة.

## التشغيل المحلي على Termux

ثبّت المتطلبات مرة واحدة:

```bash
pkg update -y && pkg install python ffmpeg git -y
```

ثم شغّل الموقع والمعالجة معاً:

```bash
cd ~/videofx-style-web && bash run_termux.sh
```

ثم افتح `http://127.0.0.1:5000` في المتصفح. لا تغلق جلسة Termux أثناء المعالجة.

## حدود الخدمة

للحفاظ على استقرار الجوال، يُفضّل البدء بملفات أقل من 450MB. الحد الفعلي يتأثر بمدة الفيديو وذاكرة الجهاز ومساحة التخزين المتاحة.
