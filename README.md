# VideoFX Style — بوقاصد اليافعي

موقع ويب مستقل لتطبيق preset بصري مستوحى من الفيديو المرجعي 96518 على فيديوهات PUBG. لا يحتوي هذا المشروع على كود تطبيق Android ولا يعتمد على حزمة Expo.

## الوظائف

يقبل الموقع ملفات الفيديو، يرسلها إلى خدمة VideoFX، يطبق وضع `style` باستخدام PUBG Clean Clarity، ثم يعرض التقدم ويوفر تنزيل الناتج. يحافظ المسار على أبعاد المصدر واتجاهه وFPS والتوقيت، مع معالجة لونية ووضوح ونعومة خفيفة.

## التشغيل المحلي

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## حدود الخدمة

للحفاظ على استقرار Render، يرفض الموقع الملفات الأكبر من 450MB قبل الرفع. الحد الفعلي قد يتأثر بمدة الفيديو وذاكرة الخدمة.
